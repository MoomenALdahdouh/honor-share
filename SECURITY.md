# Security Policy

Direct Share never uploads files. Transfers stay on your Wi-Fi, over TLS, with SHA-256 checks.

Please report vulnerabilities through [GitHub security advisories](https://github.com/MoomenALdahdouh/honor-share/security/advisories/new) instead of a public issue.

How the protocol authenticates devices, pins certificates, and stores files is documented in [docs/SECURITY.md](docs/SECURITY.md).
